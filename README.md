NZXT WYSIWYG Editor for creating Custom Web Integrations.
Use the Editor to build your display preview, it loads an example by default or start completely fresh.

Once you have your layout, export the html and host is somewhere like github pages. (index.html)
In NZXT Cam, add a custom web integration and add your url to your html file there. e.g.  https://cre4mpie.github.io/nzxt-kraken-dashboard/
I have tested this with my Z73
Comments and feedback welcome.Still some issues to work out. *shrug*

Enjoy.
